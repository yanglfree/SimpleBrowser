FIRST_ANCHOR Reader extraction begins

Reader mode must preserve the complete article rather than treating the first group of long paragraphs as the whole story. This opening paragraph establishes a stable beginning anchor for the golden fixture.

A semantic platform container should outrank arbitrary content blocks. The extractor must copy the complete body before removing navigation, comments, recommendations, forms, scripts, and other page chrome.

Long-form pages frequently combine paragraphs, sections, images, emphasized spans, lists, and headings. Candidate scoring must not depend on one specific publishing template or on detached innerText alone.

Changing font size, line height, or paper color must restyle the extracted article without running a second extraction that can select a different candidate or lose the saved scroll position.

Golden fixtures are deterministic. A frozen DOM makes failures reproducible even when the live publisher changes markup, requires authentication, performs an anti-bot redirect, or removes the original page.

Completeness is not the same as returning a non-empty string. A partial result with only the opening paragraphs is a failure when the source contains a much longer body and important material near the end.

MIDDLE_ANCHOR Quality gates are measurable

The middle anchor catches prefix-only extraction. Tests also check paragraph count, output length, retained ratio, image preservation, and the absence of known navigation or recommendation text.

Reader extraction and offline article capture must share the same candidate selection and cleanup core. Different wrappers may render HTML or generate Markdown, but they must begin with the same extracted node.

Fallback extraction may combine valid paragraphs when no semantic container exists, but it must inspect the entire document. It must never stop after an arbitrary character budget and silently report success.

Unknown pages can return partial or unavailable. Explicit uncertainty is safer than presenting a truncated document as complete, because telemetry and user feedback can then distinguish quality from availability.

Privacy-safe metrics contain only the host and coarse numeric buckets. They never contain a page path, title, extracted sentence, image URL, selected text, form value, or any other article content.

Dynamic browser canaries detect publisher drift, while local fixtures remain the release gate. A network failure is recorded separately and cannot be confused with a regression in the extraction algorithm.

Device tests serve the same fixture over a local HTTP endpoint so ArkWeb exercises its real JavaScript and DOM behavior. Build success alone does not prove that reader interaction works on hardware.

Every reported failure becomes a permanent fixture. This turns production discoveries into durable coverage and prevents a later scoring adjustment from reopening an already repaired class of data loss.

Clean output should retain legitimate technical prose even when a class name happens to contain a suspicious substring. Noise removal must use explicit page chrome signals and avoid broad destructive guesses.

Images using data-src are normalized before rendering so lazy-loaded illustrations remain available. Unsafe scripts, event handlers, javascript links, forms, and embedded frames are excluded from the result.

The extraction result includes the chosen strategy, candidate size, output size, retained ratio, paragraph count, image count, and elapsed time. These fields support tests and coarse telemetry.

Repeated extraction against the same frozen DOM must produce the same normalized text and quality classification. Determinism makes regression diagnosis fast and prevents flaky release gates.

Negative fixtures such as search pages and navigation directories ensure that a larger recall target does not create an unacceptable false-positive rate for pages that are not readable articles.

LAST_ANCHOR Complete articles reach their conclusion

The final anchor proves the reader retained the conclusion. When all required anchors, structure thresholds, safety checks, and quality ratios pass, the fixture can be classified as complete.
