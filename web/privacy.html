隐私政策

更新日期：2026 年 11 月 26 日

1. 核心数据默认留在本机

卓阅浏览器（Zhuo浏览器）在 HarmonyOS NEXT、iOS、macOS（含 Mac App Store 官方版与官网公证 DMG 独立分发版）以及 Android 上均无需注册账号即可使用全部核心浏览能力。浏览历史、标签页、收藏、离线文章、批注、主题、阅读位置、站点权限与拦截规则默认保存在你的设备本地沙盒中。普通使用过程中，我们不会上传访问网址、网页正文、搜索词或私密标签页内容。

2. 无痕浏览与多资料隔离

无痕标签页与普通会话隔离（macOS 端基于 WKWebsiteDataStore.nonPersistent() 内存隔离），不写入浏览历史、恢复会话、离线文章库或产品分析事件。关闭无痕标签页后，应用会请求清理对应站点数据。macOS 端支持多个人资料容器隔离，每个个人资料的 Cookie 与本地存储彼此独立。

3. 系统钥匙串、Touch ID 与安全连接

macOS 端保存的网站登录密码直接加密存储于系统登录钥匙串（Login Keychain），由 macOS 系统保护，仅应用自身可读取，并在每次自动填充前要求通过 Touch ID 或系统密码验证。可选开启的弱口令/泄露密码本地预警仅在本地特征集比对，不向外部服务器上传明文密码；安全 DNS (DoH) 仅在你主动选择第三方提供商时由系统网络层加密解析域名。

4. 可选的云端同步账号与永久注销

账号与云端同步为完全可选功能；未登录时你仍可完整使用全部核心浏览与本地阅读功能。若你主动选择跨端登录（支持邮箱 6 位验证码 / 邮箱密码，iOS 与 macOS 支持 Sign in with Apple，HarmonyOS 端支持华为账号，非中国大陆地区支持 Google 登录），系统会在 Cloudflare D1 / R2 安全存储你的账号凭据、已绑定身份（user_identities）及同步范围数据：书签与文件夹、跨平台通用偏好设置（不同设备专有硬件预算参数仅保留在本机）、站点控制规则、非私密且非空白起始页的跨设备标签页列表；若已开通 Pro 会员，还会按需同步离线文章元数据、划线批注与加密/受控 R2 离线全文快照。无痕标签页数据永不参与同步。

你可随时在各平台应用内「账号中心 → 永久注销账号」执行不可逆删除（DELETE /api/auth/account），系统将永久清除云端账号、所有同步作用域数据、设备标签页记录及 R2 中的离线文章与头像文件，本地当前已下载数据保留由你自主管理。

5. 可选的崩溃与性能统计

仅在你主动同意并开启统计开关且处于非无痕标签页时（macOS / Android 端可在设置中随时关闭），应用才会向自建统计服务 trending.youdroid.top（并在 HarmonyOS 端同步写入系统事件目录）发送不含访问网址、网站域名、网页正文、搜索词及私密会话信息的匿名可靠性与功能使用统计。关闭开关或进入无痕浏览后，应用会立即停止上报。

6. Pro 购买与跨端权益验证

购买由对应应用商店安全处理（如 HarmonyOS 华为 AppGallery IAP、iOS / macOS App Store）。为校验、恢复与防重放，应用会向 gateway.youdroid.top 发送商品 ID、订单或交易标识、原始购买凭据与随机生成的本机安装标识（install_id）；当你在多端登录同一卓阅同步账号时，授权网关会将已校验的 install_id 权益与你的 user_id 关联，使已购 Pro 会员权益（及 Pro 离线文章同步）在同一账号下的设备间共享，仍支持未登录状态下仅凭商店收据在本机验证 Pro。我们不接收你的银行卡或支付密码。

7. 权限与外部服务

只有在你触发下载、文件导入导出、分享或网站主动申请相机、麦克风、定位或打印能力时，应用才请求相应系统权限。访问的网站会按其自身隐私政策处理你提交给它们的数据。

8. 数据删除与保存期限

你可以在设置中清除历史、Cookie、网页存储、缓存、权限与例外，也可以逐项删除收藏、离线文章或个人资料容器，或在账号中心永久注销云端账号。卸载应用会删除设备上的应用数据。订单与权益记录会在履行购买、恢复、退款处理和合规义务所需期限内保存。
