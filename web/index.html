ENGINEERED FOR MACOS FRUGALITY & SPEED

为什么 Mac 需要一款 真正克制的原生浏览器？

不捆绑百兆级 Chromium 内核，不用高耗电的 JS 轮询拦截广告，也不在切换标签时偷偷重载你的表单与阅读进度。

01 · NATIVE WEBKIT SHELL

零 Chromium 膨胀，极致省内存

直接构建于 macOS 原生 WebKit.framework 与 SwiftUI 之上，底层库通过系统 dyld 共享缓存加载。无独立渲染引擎冗余，双架构 Universal 安装包仅 23.7 MB，冷启动与能效表现媲美系统原生组件。

02 · INSTANT TAB SWITCHING

常驻标签瞬时切换，可观测零重建

每个打开的标签页在整个会话期内保活独立 WKWebView。切换标签仅在视图树中重挂载（re-parent），零网络请求、零重新排版，滚动位置、DOM 状态与未提交表单完整保留。工具栏内置实时复用/重建计数器，也可按需开启 1–8 配额的省内存冻结模式（WKWebView.interactionState 快照）。

03 · ZERO-JS CONTENT BLOCKING

C++ 网络层字节码拦截，零 JS 开销

将 EasyList、EasyList China 与精选补充规则直接编译为 WebKit 原生 WKContentRuleList 二进制字节码，在 WebKit 网络进程内由 C++ 直接评估拦截，无需注入沉重的 JS 过滤脚本，支持标准/严格两档清理与单站点白名单。

04 · KEYCHAIN, TOUCH ID & PASSKEYS

系统钥匙串自动填充与 WebAuthn 通行密钥

密码直存 macOS 系统登录钥匙串（Login Keychain），聚焦登录框弹出 Safari 风格凭据建议气泡，通过 LAContext 调用 Touch ID 或系统密码完成生物识别校验后注入。完整支持 WebAuthn 标准与 iCloud 钥匙串通行密钥（Passkey）集成，并提供 HTTPS 优先自动升级与安全浏览分级防护。

05 · CHROME MV3 & USERSCRIPTS

内置 5 大精选扩展，兼容 Chrome 扩展与脚本

开箱内置「智能暗黑护眼」「沉浸式网页双语对照翻译」「音视频流媒体嗅探下载」「超级复制与解除右键限制」「UserScript 脚本工坊」五大工具。支持开发者模式加载已解压目录、导入 .crx / .zip / .user.js 及站点级权限管控。

06 · PURE MACOS EXPERIENCE

纯粹 Mac 桌面体验与云端壁纸归档

零网络、零 DOM 的原生极简起始页，接入 Cloudflare D1 + R2 必应每日高清壁纸历史归档与精选预设；自适应多标签栏宽度压缩、OAuth 独立登录弹窗（保留 window.opener）、书签与历史记录资料库、完整键盘快捷键（⌘T / ⌘L / ⌘D / ⌘Y / ⌘1~9）及一键设为默认浏览器。
