退后一步的浏览器哲学

Zhuo浏览器（原卓阅浏览器）不在用户设备上再塞入一套臃肿的第三方运行时。macOS 端直接基于系统共享的 WebKit 与 SwiftUI 构建，HarmonyOS NEXT 端基于 ArkTS 与 ArkWeb 原生实现，动态链接库与系统共享缓存复用，安装包仅 23.7 MB。

当浏览器本身退后一步，地址栏、标签条与工具栏便只保留必要的功能入口。必要时能力触手可及，其余时间，屏幕只留给网页与文字本身。

在常规浏览会话中，每一个打开的标签页都默认持有各自活跃的原生 WKWebView 实例。切换标签只是重新挂载已经完成排版的视图层级——不重新发起网络请求，不丢失滚动位置、表单输入、DOM 状态与前进后退历史。

如果你同时开启几十个参考页面或工作在内存紧张的设备上，可在设置中随时开启「省内存模式」，设定 1 至 8 个常驻活跃标签上限。超出配额的后台标签会通过 WKWebView.interactionState 序列化为交互快照并释放渲染进程，唤醒时自动还原上下文；而系统的警告级内存压力不会打断当前浏览，仅在临界内存压力下按最近最少使用顺序触发应急冻结。

关于「0 重载」的可观测契约

工具栏中的状态指示器（切换复用 / 页面重建）让标签切换行为随时可观测。在正常保活会话中，每一次标签切换都保证复用现有视图；已冻结标签也会清晰标识睡眠与快照时效，超过时效后自动透明刷新。

macOS 端通过原生内容规则编译器，将内置的 EasyList 精选规则编译为 WKContentRuleList 二进制字节码，交由 WebKit 网络进程在 C++ 层直接拦截广告、追踪器与弹窗请求；HarmonyOS 端则直接调度 ArkWeb AdsBlockManager 进行分类拦截统计。无需向页面注入沉重的 JavaScript，遇到需要放行的网站时，可在地址栏一键加入单站点白名单。

围绕日常高频阅读与查阅场景，浏览器原生内置了暗黑护眼、网页双语翻译、流媒体嗅探、超级复制与脚本管理五大工具，在 App Sandbox 下安全运行。若你在 macOS 桌面端需要更丰富的扩展生态，官网公证独立分发版额外支持导入已解压或 .crx 格式的 Chrome MV3 扩展以及 .user.js 用户脚本。

macOS 登录钥匙串 + Touch ID

安装后无需登录任何账号即可使用全部核心浏览功能。浏览历史、书签、离线文章、批注、站点权限与拦截规则默认保存在设备本地沙盒中，日常访问的网址、网页正文与搜索词不会上传至任何服务器。无痕标签页在 macOS 端基于 WKWebsiteDataStore.nonPersistent() 运行于独立内存，不写入历史记录或会话恢复文件，关闭标签即刻销毁；多个人资料容器更可将不同工作身份的 Cookie 与存储完全隔离。

网站密码直接加密存入 macOS 系统登录钥匙串，每次自动填充均需通过 Touch ID 或系统密码验证，并完整支持 WebAuthn 通行密钥与安全 DNS（DoH）。如果你选择开启可选的云端同步以在设备间延续书签与偏好设置，仅你主动同步的配置会保存在加密存储中，且随时可在应用内「账号中心」一键永久注销账号并清除全部云端记录。
