离线文章验收夹具

这是一篇用于验证卓阅离线文章能力的本地长文。正文包含可检索关键字“星河书签”，并会在停止服务器后继续接受离线阅读验证。

第一节：可靠保存

保存操作应提取标题、作者、正文、图片与规范链接。任何失败都必须给出明确反馈，同时不得破坏此前已经成功保存的版本。

本段用于增加阅读长度。浏览器应该将文章内容写入应用支持目录，将元数据与正文分开管理，并限制图片数量、单张大小和总体积。

第二节：离线阅读

停止本地服务器后，离线阅读器仍应显示完整标题和正文。离线页面不得自行连接远程网络，用户点击外链时应回到普通浏览标签页。

本段包含高亮目标：真正可靠的离线阅读需要稳定的内容身份。用户可以选中这句话并保存高亮，之后重新进入文章仍能看到标记。

第三节：整理与检索

标签适合描述文章属性，主题适合聚合长期关注方向，笔记则承载用户自己的判断。搜索需要同时覆盖标题、正文、标签、主题、笔记和高亮。

本段用于继续拉长页面，确保阅读位置不是一个接近零的偶然值。页面重新打开时应恢复到用户上次阅读附近，而不是永远回到顶部。

第四节：导出

Markdown 和 HTML 导出必须来自本地保存副本。图片引用应内嵌到导出文件中，使接收方不依赖应用内部目录也能保留内容。

验收完成后，资料库应清楚显示文章质量、来源、更新时间与整理标签。归档不会删除内容，删除则需要明确确认并级联清理所有本地文件。

第五节：最终检查点

这是页面底部的最终检查点。看到本段说明长文可以完整滚动，后续冷启动恢复可以用它确认阅读位置已经持久化。
